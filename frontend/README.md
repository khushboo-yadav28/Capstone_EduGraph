# EduGraph Frontend - Knowledge Graph Adaptive Courseware System

EduGraph Frontend is built using **Next.js**, **Tailwind CSS**, and **TypeScript**, delivering an adaptive, interactive learning experience backed by knowledge graphs and AI-powered assessments.

## Tech Stack
* **Framework:** Next.js (React / App Router)
* **Styling:** Tailwind CSS, Lucide Icons
* **API Client:** Axios / Fetch integrations with FastAPI backend
